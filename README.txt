======================================
        BENZ GARAGE v2.0
   Student Data Management System
======================================

DESCRIPTION:
A command-line app to manage student records for a driving school.
Built with Python. No external libraries needed.

FEATURES:
1.  Full CRUD: Add, View, Update, Delete students
2.  Reports: Richest, Poorest, Average Money in Garage
3.  Search & Sort: Find by City, Sort by Money
4.  Data Safety: Auto-save, Backup with date, Load different files
5.  Export: Send data to Excel/CSV for accountants
6.  Statistics Dashboard: Total students, Total money, Average age
7.  Crash Proof: Input validation so app never crashes

HOW TO RUN:
1.  Make sure you have Python 3 installed
2.  Run: python Benz_Garage.py

TECH STACK: Python, File Handling, Dictionaries, CSV
